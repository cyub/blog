## 电子电路基础知识

### 欧姆定律

在导体的两端加上电压，导体内的电子就会在电场力的作用下作定向运动，形成电流。电流的方向规定为电子（负电荷）运动的反方向，即**电流的方向与电子运动的方向相反**。

![](https://static.cyub.vip/images/202611/circuit-battery-switch-bulb-tikz.svg)

上图中由电池、开关、灯泡组成的电路模型，当开关闭合时，电路形成通路，电池的电动势形成了电压，继而产生了电场力，在电场力的作用下，处于电场内的电子便会定向移动，这就形成了电流。

电压也称电位差（或电势差），单位是伏特（$V$）。电流之所以能够在电路中流动是因为电路中存在电压，即高电位与低电位之间的差值。电位是指该点与指定的零电位的大小差距。电位也称电势，单位是伏特（$V$），用符号“φ”表示，它的值是相对的，电路中某点电位的大小与参考点的选择有关。

电阻是指物质对所通过的电流产生的阻碍作用。

欧姆定律是电路中最基本的定律之一。欧姆定律规定了电压（$U$）、电流（$I$）和电阻（$R$）之间的关系:

> 在电路中，流过电阻器的电流与电阻器两端的电压成正比，与电阻成反比，即$I=U/R$

### 电功率与焦耳定律

#### 电功

电能可以转化成多种其他形式的能量。电能转化成多种其他形式能的过程也可以说是电流做功的过程，有多少电能发生了转化就说电流做了多少功，即电功是多少。电功的计算公式为：

$$
W = UIt
$$

上面公式中$U$为电压，$I$为电路中的电流，$t$为通电时间，$W$为电功，单位焦耳($J$)。

#### 电功率

电功率是指电流在电位时间内（秒）所做的功，以字母“$P$”标识，单位为瓦特(W）即:

$$
P = W/t = UIt/t = UI
$$

电动机的额定电压为$220V$, 额定电流为$10A$，则其电功率为：$P = UI = 220V \times 10 A = 2200W$。

电功率常用千瓦(kW)，毫瓦(mW), 马力(非标准单位)来表示：

$$
1kW = 10^3W\\\\
1mW = 10^{-3}W\\\\
1马力 = 0.735kW\\
$$

根据欧姆定律，电功率还可以转换为:

$$
\begin{align}
P = W/t = UIt/t = UI = (IR)I  = I^2R
\end{align}
$$

$$
\begin{align}
P = W/t = UIt/t = UI = U(U/R) = U^2/R
\end{align}
$$

从上面公式可以得到：
- 在电流一定时候，电功率与电阻成正比
- 在电压一定时候，电功率与电阻成反比

电气设备正常工作时的最大电压叫**额定电压**，在额定电压下的电功率叫**额定功率**。

#### 焦耳定律

导体中有电流通过时，导体就会发热，这种现象叫做电流的热效应。

英国物理学家焦耳于1840年最先确定了电流产生的热量跟电流、电阻和通电时间的定量关系，这个定量关系，叫做焦耳定律：电流通过导体产生的热量与电流的平方成正比，与导体电阻成正比，与通电时间成正比：

$$
Q = I^2Rt
$$

### 电子电路的连接关系

#### 串联电路

如果电路中多个负载首尾相连，那么就称它们的连接状态是串联的，该电路即称为串联电路。
串联电路可以分为电阻器的串联、电容器的串联、电感器的串联。

##### 电阻器的串联

![](https://static.cyub.vip/images/202611/circuit-series-resistors.svg)

由于电路中各处电流相等,总的电压等于各个电阻的电压之和：

$$
\begin{align}
U &= U_1 + U_2 + \cdots  + U_n \\\\
&= IR_1 + IR_2 + \cdots + IR_n \\\\
&= I(R_1 + R_2 + \cdots + R_n)
\end{align}
$$

所以串联后的总电阻$R$:

$$
R = U/I = R_1 + R_2 + \cdots + R_n
$$

于是：

$$
R = R_1 + R_n + \cdots + R_n
$$

##### 电容器的串联

电容器是由两片极板组成的，具有存储电荷的功能。电容器所存的电荷量（Q）与电容器的容量和电容器两极板上所加的电压成正比。

$$
Q = UC
$$

![](https://static.cyub.vip/images/202611/circuit-series-capacitors.svg)

串联电路中各点的电流相等，那么通过每个电容器的电荷量都是相同的，而电压等于各个电容器的电压之和，于是有：

$$
\begin{align}
U &= U_1 + U_2 + \cdots + U_n\\\\
&= \frac{Q}{C_1} + \frac{Q}{C_2} + \cdots + \frac{Q}{C_n}\\\\
&= Q(\frac{1}{C_1} + \frac{1}{C_2} + \cdots + \frac{1}{C_n})\\\\
\end{align}
$$

我们将串联的电容器视为一个电容器$C$:

$$
U = \frac{Q}{C} = Q(\frac{1}{C_1} + \frac{1}{C_2} + \cdots + \frac{1}{C_n})
$$

于是：

$$
\frac{1}{C} = \frac{1}{C_1} + \frac{1}{C_2} + \cdots + \frac{1}{C_n}
$$

也就是说：串联电容器的合成电容量的倒数等于各电容器电容量的倒数之和。

##### 电感器的串联

电感（英语：Inductance）是闭合回路的一种属性，即当通过闭合回路的电流改变时，会出现电动势来抵抗电流的改变。如果这种现象出现在自身回路中，那么这种电感称为自感（self-inductance），是闭合回路自己本身的属性。

通常自感是以字母“L”标记，以纪念物理学家海因里希·楞次。电感的单位是亨利（Henry），标记为“H”，以纪念科学家约瑟·亨利。

![](https://static.cyub.vip/images/202611/circuit-series-inductors.svg)

串联电路中各点的电流相等，而电压等于各个电容器的电压之和，于是：

$$
\begin{align}
U &= U_1 + U_2 + \cdots + U_n\\\\
&= L1\cdot\frac{di}{dt} + L2\cdot\frac{di}{dt} + \cdots + L_n\cdot \frac{di}{dt}\\\\
&= (L_1 + L_2 + \cdots + L_n)\frac{di}{dt}
\end{align}
$$

我们将串联的电感起视为一个电感器$L$:

$$
U = L\frac{di}{dt} = = (L_1 + L_2 + \cdots + L_n)\frac{di}{dt}
$$

于是：

$$
L = L_1 + L2  + \cdots + L_n
$$

也就是说：串联电感器的合成电感量等于各电感器电感量之和。

#### 并联电路

两个或两个以上负载的两端都与电源两极相连，则称这种连接状态是并联的，该电路即为并联电路。

##### 电阻器的并联

![](https://static.cyub.vip/images/202611/circuit-parallel-resistors.svg)

并联电路中，各并联电阻器两端的电压是相等的，电流为各个通过电阻器的电流之和。

$$
\begin{align}
I &= I_1 + I_2 + \cdots + I_n\\\\
&= \frac{U}{R_1} + \frac{U}{R_2} + \cdots + \frac{U}{R_n}\\\\
&= U(\frac{1}{R_1} + \frac{1}{R_2} + \cdots + \frac{1}{R_n})\\\\
\end{align}
$$

我们将串联的电阻起视为一个电阻器$R$:

$$
I = \frac{U}{R} = U(\frac{1}{R_1} + \frac{1}{R_2} + \cdots + \frac{1}{R_n})
$$

于是：

$$
 \frac{1}{R} = \frac{1}{R_1} + \frac{1}{R_2} + \cdots + \frac{1}{R_n}
$$

也就是说：并联电路总电阻的倒数等于各并联支路电阻的倒数之和。

##### 电容器的并联

在并联电路中，各并联电阻器两端的电压是相等的，总电流等于各分支电流之和，那么通过每个电容器的电荷量之和等于总的电荷量。

![](https://static.cyub.vip/images/202611/circuit-parallel-capacitors.svg)

$$
Q = CU = C_1U + C_2U + \cdots + C_nU = (C_1 + C_2 + \cdots + C_n)U
$$

于是：

$$
C = C_1 + C_2 + \cdots + C_n
$$

也就是说：并联电路中，各并联电阻器两端的电压是相等的。

##### 电感器的串联

![](https://static.cyub.vip/images/202611/circuit-parallel-inductors.svg)

并联电感的倒数等于三个电感的倒数之和；

$$
\frac{1}{L} = \frac{1}{L_1} + \frac{1}{L_2} + \cdots + \frac{1}{L_n}
$$

##### 混联电路

既有电阻器串联又有电阻器并联的电路称为混联电路。

### 直流电与交流电

#### 直流电

直流电（Direct Current，简称DC）是指电流方向不随时间作周期性变化，由正极流向负极，但电流的大小可能会变化。直流电可以分为脉动直流和恒定直流两种。脉动直流中电流大小不稳定，而恒定直流中的电流大小是恒定不变的。

![](https://static.cyub.vip/images/202611/dc-waveforms.svg)

一般将可提供直流电的装置称为直流电源，例如干电池、蓄电池、直流发电机等。当直流电源为电路供电时，直流电源能够使电路两端之间保持恒定的电位差，从而在外电路中形成由电源正极到负极的电流。
