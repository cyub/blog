## OpenClaw 是什么？

![](https://static.cyub.vip/images/202602/openclaw-logo-text-dark.png)

**[OpenClaw](https://github.com/openclaw/openclaw)**（原名 Clawdbot → Moltbot → OpenClaw）是一个**开源 AI 代理框架**，由奥地利独立开发者 Peter Steinberger 创建。它不是一个大模型，而是一个**"给 AI 装上爪子的执行系统"**。

简单来说：

- **GPT/Claude** 是"大脑"——只能思考和建议
- **OpenClaw** 是"手脚"——能真正操作你的电脑执行任务

它运行在你的本地设备（Mac/PC）或私有服务器上，通过 WhatsApp、Telegram、Slack、飞书、钉钉等日常聊天软件与你交互，拥有读写文件、执行终端命令、操控浏览器、访问邮件日历等**系统级权限**。

<!-- more -->

龙虾吉祥物 🦞 已成为它的标志性符号，用户常亲切地称它为“我的小龙虾”或“Clawd”。OpenClaw 核心亮点有：

- Gateway 架构：本地 WebSocket 控制面，支持多代理路由与沙箱隔离
- 持久记忆：Markdown 文件（SOUL.md 定义人格、USER.md 用户画像、MEMORY.md 关键事实）+ 向量数据库
- Skills 生态：社区贡献 1700+ 技能，AI 可自主编写并学会使用
- 多模型支持：Claude Opus、GPT、Gemini、本地 Ollama、MiniMax 等，随意切换

## 为什么突然爆火？

2025 年底 Peter 将它作为一个周末项目（最初叫“WhatsApp Relay”）启动，2026 年 1 月底正式开源并改名后，短短三周 GitHub 星标从 0 冲到 10 万+，目前已突破 228k（史上增长最快的开源项目之一）。它还带动了 Mac Mini 销量、催生了 AI-only 社交网络 Moltbook，并登上 Lex Fridman 播客。
它的爆火并非偶然，而是精准切中了几个关键痛点：

### 1. 极致的平民化与易用性

OpenClaw 最大的创新在于**把技术门槛降到了零**。它不需要你安装新应用、学习编程术语或配置复杂环境，而是直接接入你**已经在用的聊天软件**（微信、飞书、钉钉等）。发消息就能指挥 AI 干活，这种"零学习成本"的设计让它瞬间破圈。

无需安装新 App、无需学 Prompt 工程、无需配置环境。一行命令安装：

```bash
curl -fsSL https://openclaw.ai/install.sh | bash
```

然后 `openclaw onboard` 即可。普通人用飞书发一句“帮我整理下周东京行程并订机票”，它就真去干了。

### 2. 从"聊天"到"干活"的质变

之前的 AI 助手（如 ChatGPT）是"缸中之脑"——很聪明但被困在浏览器里。OpenClaw 第一次让普通用户意识到：**AI 真的能替我操作电脑**。它可以：

- 自动整理文件、部署环境、爬取网页数据
- 跨应用操作（如在飞书里发指令，让它去查邮件、写报告、发回文件）
- 24 小时后台运行，像"隐形员工"一样自主完成任务

### 3. 持久记忆与自我进化

OpenClaw 拥有独特的**双轨记忆系统**：

- **显性记忆（MEMORY.md）**：存储你的偏好、工作风格等关键信息
- **隐性记忆（向量数据库）**：自动捕获对话中的零散事实（比如你一个月前说胃不好，今天点外卖时它会主动避开冰饮）。 AI 还能自己写 Skills、优化自身 Prompt，形成真正自我进化的“数字分身”。

加上 **Skills 插件生态**（社区已贡献 1700+ 技能），AI 能自己写新技能并记住用法，形成**自我进化的闭环**。

### 4. 开源与数据主权

在 AI 巨头垄断的时代，OpenClaw 坚持**本地优先、自托管、MIT 开源协议**。你的数据完全属于自己，不会被上传到云端训练模型。这种"掌控感"击中了用户对隐私和自主权的深层渴望。



## 它做对了什么？

| 关键决策 | 具体做法 | 效果 |
|---------|---------|------|
| **选对入口** | 复用现有聊天软件（WhatsApp/飞书/钉钉），而非新建 App | 零学习成本，用户基数瞬间最大化 |
| **统一上下文** | 所有对话历史共享一个记忆池，跨平台、跨会话保持连贯 | AI 越用越"懂你"，产生情感连接 |
| **文件即记忆** | 用 Markdown 文件（SOUL.md、USER.md、MEMORY.md）存储人格、用户画像和记忆 | 透明、可编辑、可版本控制 |
| **开放工具生态** | 支持 1700+ Skills 插件，覆盖从自动化部署到数据分析的全场景 | 能力持续扩展，社区飞轮效应 |
| **多模型支持** | 不绑定单一模型，支持 Claude、GPT、Gemini、DeepSeek、Ollama 本地模型等 | 避免 vendor lock-in，灵活性最大化 |

## 它能解决什么问题？

**对个人用户**：

- **自动化繁琐任务**：邮件分类、日程安排、文件整理、数据爬取
- **跨应用协作**：在手机上用飞书指挥家里的电脑生成报表、部署服务
- **长期个人助理**：记住你的习惯、偏好，越用越顺手，成为真正的"数字分身"

**对开发者**：

- **快速搭建 AI Agent**：无需从零构建复杂架构，一条命令即可启动
- **私有化部署**：适合对数据安全敏感的企业场景
- **可扩展架构**：通过 Skills 系统轻松定制专属能力

**对行业**：

OpenClaw 代表了 **"Agentic AI"（智能体 AI）** 的平民化落地。它证明了：**技术整合与用户体验设计，有时比底层技术创新更具爆发力**。它也让"一人独角兽"（一个人+AI 团队完成传统公司的工作）成为可能。


## 争议与风险

OpenClaw 的"暴力美学"也带来了巨大争议：

- **安全风险**：拥有 root 权限的 AI 可能误删文件、执行危险命令
- **隐私悖论**：虽然数据本地存储，但 AI 能访问你的所有文件和通信
- **厂商博弈**：手机厂商（苹果、谷歌）视其为安全威胁，而云厂商（阿里云、AWS）则狂热推广，因为创造了 VPS 算力刚需

正如一位开发者所言："OpenClaw 不是终点，它是一个路标。它告诉我们 AI Agent 的未来有多么迷人，同时也提醒我们，通往那个未来的道路上布满了多少地雷。"

## 快速上手指南

1. 安装（5 分钟）：一行 curl 脚本，支持 Docker / Nix / 直接 Node.js ≥22
2. Onboard：运行 `openclaw onboard`，选择模型、连接聊天账号（推荐 Claude Opus 4.x）
3. 权限管理：从沙箱模式开始，逐步开放文件/浏览器权限
4. 日常使用：发消息即可，例如：
    - “帮我总结今天 Gmail 未读邮件并生成周报”
    - “检查我的 WHOOP 数据，调整明天跑步计划”
    - “打开浏览器帮我买张周五去上海的高铁票”

5. 进阶：去 ClawHub 搜索技能，或直接对它说“写一个控制空气净化器的 Skill”

整个过程对非程序员也极其友好，已有大量用户在树莓派或旧 Mac 上 24 小时常驻运行。


总之，OpenClaw 的爆火不是因为它发明了新技术，而是因为它**第一次把"能动手干活的 AI"送到了普通用户手中**，用极致的易用性和情感化设计，让科幻电影中的"贾维斯"变成了现实。
